# Folder Foto

Tempatkan foto-foto berikut di folder ini:

## Foto yang Diperlukan:

1. **kepala_desa.jpg** - Foto Kepala Desa (Hukum Tua)
2. **sekdes.jpg** - Foto Sekretaris Desa
3. **hero-bg.jpg** - Background untuk hero section (opsional, bisa landscape desa)
4. **oma_lina.jpg** - Foto warga untuk testimonial
5. **rico.jpg** - Foto warga untuk testimonial

## Spesifikasi Foto:

- **Foto Perangkat Desa**: Rasio 3:4 (portrait), minimal 600x800px
- **Hero Background**: Rasio 16:9 (landscape), minimal 1920x1080px
- **Foto Warga**: Rasio 1:1 (square), minimal 400x400px

## Format:
- JPG atau PNG
- Ukuran file maksimal 500KB per foto untuk performa optimal

## Tips:
- Gunakan foto dengan pencahayaan yang baik
- Pastikan foto tidak blur
- Compress foto sebelum upload untuk performa website yang lebih baik
